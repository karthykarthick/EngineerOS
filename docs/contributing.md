# 🤝 Contributing

EngineerOS follows a feature-based development workflow.

## Branch Strategy

main

↓

dev

↓

feature/*

---

## Commit Convention

feat:

fix:

docs:

refactor:

chore:

---

## Pull Requests

Every feature should be developed in its own branch and merged into dev through a Pull Request.

---

## Coding Standards

- Use TypeScript
- Write readable code
- Prefer reusable components
- Keep components small
- Document important decisions
